# WA Cross Sell для OpenCart

Безкоштовний модуль додаткових пропозицій на сторінці товару. Версія **1.0.0**, український інтерфейс, GPL-3.0-or-later. Без ліцензійного ключа, реєстрації, телеметрії та зовнішніх API.

Для кожного основного товару створіть екземпляр модуля, задайте ID додаткових товарів у потрібному порядку й підключіть до стандартного макета Product. Покупець побачить зображення, назви, доступні йому ціни та посилання на картки товарів.

## Вимоги та сумісність

- OpenCart **3.0.3.9** зі стандартною темою; функціонально перевірено на PHP **8.2** / MySQL **8.0** у чистій локальній установці OpenServer.
- Код призначений для OpenCart 3.x, але інші мінорні версії, ocStore, сторонні теми та OpenCart 4 не сертифіковані. OpenCart 4 не підтримується.
- PHP GD, Zip та звичайні вимоги OpenCart. Потрібні права адміністратора на встановлення розширень і редагування макетів.
- Українські рядки включені для `uk-ua` та резервної `en-gb`, щоб модуль був українським і на чистому OpenCart. Переклад усієї CMS не входить до пакета.

## Встановлення

1. Збережіть резервну копію своїх налаштувань/файлів і перевірте модуль на тестовій копії магазину.
2. Завантажте **`wa-opencart-cross-sell-1.0.0.ocmod.zip`** з [GitHub Releases](https://github.com/NikitaKobzar/wa-opencart-cross-sell/releases), звірте SHA-256 з `SHA256SUMS.txt`.
3. В адмінці: **Extensions → Installer** (Розширення → Встановлення розширень), завантажте ZIP без розпакування. Суфікс `.ocmod.zip` потрібен інсталятору; пакет не містить модифікацій ядра або `install.xml`.
4. **Extensions → Extensions → Modules**, знайдіть **WA Cross Sell** та натисніть встановлення. Відкрийте редагування.
5. Заповніть назву екземпляра, заголовок, ID основного товару та ID додаткових через кому, наприклад `42,43,44`. ID видно в URL редагування товару як `product_id=42`.
6. Виберіть кількість карток (1–12), розміри зображень (40–1000 px), стан «Увімкнено» та збережіть.
7. **Design → Layouts → Product**, додайте створений екземпляр до **Content Bottom**, збережіть. Якщо товару призначено власний макет, додайте модуль саме до нього.
8. Відкрийте сторінку основного товару як покупець. Для іншого основного товару створіть інший екземпляр. Дозволи інших адміністраторів налаштовуються в **System → Users → User Groups** для `extension/module/wa_cross_sell`.

Якщо ZIP-інсталятор недоступний, адміністратор може вручну скопіювати **лише вміст `upload/`** до кореня OpenCart, зберігаючи структуру. Не замінюйте каталоги цілком. Після цього виконайте кроки 4–8.

## Правила відображення

- Показ лише на сторінці налаштованого основного товару. Повторні ID та сам основний товар пропускаються.
- Вимкнені, видалені, майбутні або не призначені поточному магазину товари не показуються. Якщо всі пропозиції недоступні, блок не виводиться.
- Товар без залишку пропускається, коли стандартне налаштування OpenCart забороняє продаж без залишку; коли дозволяє — може показуватись.
- Ціни беруться зі штатної моделі OpenCart: група покупця, акція, податки та валюта сесії. Якщо ціни приховані для гостей, модуль приховує і звичайну, і акційну ціну.
- Кнопка відкриває картку товару; опції й додавання до кошика залишаються стандартними. Комплекти, пакетна знижка, AI-рекомендації, масовий імпорт зв'язків та статистика конверсій не входять до версії 1.0.0.
- Немає змін ядра, OCMOD/VQMod, власних таблиць, копій товарів чи залежності від платної теми. Налаштування зберігаються в штатній таблиці модулів OpenCart.

## Оновлення та видалення

Перед оновленням збережіть налаштування екземплярів та копію поточних файлів. Прочитайте `CHANGELOG.md`, установіть новий ZIP поверх файлів без видалення екземплярів і перевірте картки/ціни на тестовій копії. Старі ZIP у Releases незмінні. Автоматичного оновлювача немає.

Для видалення спершу приберіть екземпляри з макетів, потім видаліть їх у Modules та деінсталюйте WA Cross Sell. У Installer видаліть запис встановлення, щоб прибрати файли пакета, або вручну видаліть тільки файли зі списку `FILES.txt`. Товари, замовлення та інші модулі не видаляються. Деінсталяція модуля видаляє його налаштування; відновлення — установити пакет і повернути збережені налаштування.
